# .marketing/plan.md template

```markdown
# GTM plan — <product>

**Goal**: <one measurable line, with a date>
**Stage**: launched | prelaunch (launch target: <date>)
**Current rung**: <reachable|known|associated|preferred|converting>, from `gtm.py ladder` on <date>
**Budget**: $<cap>/month (spent this month: see digest)

## Active bets
| id | hypothesis | action (skill → output) | target prompts | started | check on | result |
|---|---|---|---|---|---|---|
| B1 | Allowing AI search bots makes the site citable | ai-search-optimization → PR #n | all | 2026-11-02 | 2026-11-23 | |
| B2 | A page on "<intent>" flips cat-03 on ChatGPT and Perplexity | one-pager → PR #n | cat-03, prob-02 | | | |

## Backlog (ranked)
1. <action> — rung <r> — impact/confidence/effort — source (audit run, probe, target)
2. …

## Learnings
- <date> — <lever> moved <engine> on <bucket> in <n> weeks (bet B2). Confidence +.
- <date> — Outreach to <kind of page> landed 1 of 6; editors want data, not product claims.

## Decisions waiting on a human
- <proposal, e.g. raise budget to $40 to sample key prompts 3×> — proposed <date>

## Log
- <date> tick: audit, watch. Named 12% → 15%. Drafted 3 pitches.
```

Rules:

- A bet without target prompts and a check date isn't a bet. Don't start it.
- Close every bet: `won`, `lost`, `inconclusive`, with numbers. Inconclusive bets usually mean the
  panel lacks a prompt for the intent, so add one through `panel_review`.
- Keep learnings short and specific to this product. They are what makes month three smarter than
  month one.
